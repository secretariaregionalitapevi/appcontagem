# Scripts SQL

Scripts de estrutura, permissões, atualização de dados e consultas administrativas.
Execute somente o arquivo necessário no SQL Editor do Supabase; esta pasta não possui execução automática.

- `REUNIAO_APRIMORAMENTO_2026-11-28.sql`: estrutura e funções da reunião pública.
- `LISTA_CONFIRMACOES_REUNIAO_2026-11-28.sql`: consulta para exportação da lista.
- `RECUPERAR_CONFIRMACOES_REUNIAO_2026-11-28.sql`: recuperação pontual do fluxo anterior.
- `RLS_POLICY_*.sql`: permissões de acesso.
- `ATUALIZAR-CADASTRO-SAM-*.sql` e `corrigir_*.sql`: manutenção específica do cadastro.

Instruções do fluxo público: [documentação da reunião](../docs/PUBLIC_MEETING.md).
